Trabajo Práctico Integrador I — Sistema de Gestión de Blog Personal con Autenticación

Proyecto backend desarrollado con Node.js, Express y Sequelize (MySQL) que implementa:

- Autenticación con JWT y cookies httpOnly.
- Hasheo de contraseñas con bcrypt.
- Validaciones con express-validator.
- Relaciones de Sequelize 1:1, 1:N y N:M.
- CRUD completo con eliminación en cascada y eliminación lógica (paranoid).
